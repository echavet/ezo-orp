# Brand assets — EZO Complete-ORP

Original icon (not an Atlas Scientific trademark). Teal droplet + millivolt waveform on an ORP probe.

## Layout for Home Assistant

### Local (HA ≥ 2026.3)

Shipped with the integration:

```text
custom_components/ezo_complete/brand/
  icon.png
  logo.png
  icon@2x.png
  logo@2x.png
  icon_dark.png
  logo_dark.png
```

### Optional: home-assistant/brands

For older HA versions / CDN `brands.home-assistant.io`, open a PR to
[home-assistant/brands](https://github.com/home-assistant/brands) under:

```text
custom_integrations/ezo_complete/
  icon.png
  logo.png
  icon@2x.png
  logo@2x.png
```

Copy files from this `brands/ezo_complete/` directory (square 256 / 512 PNG).
